# 𒀱ℂ𝕄𝔼ℙ𝕋𝕓𒀱 — Telegram Mini App starter

## Что это
- `bot.py` — Telegram bot + Flask API.
- `webapp/index.html` — Telegram Mini App interface inspired by the supplied screenshot.
- Каталог содержит список серверов и демо-позиции донатов/кейсов для каждого сервера.
- Оплата цифровых товаров запускается через Telegram Stars (`XTR`).
- Mini App проверяет `Telegram.WebApp.initData` на сервере.

## Важно
Демо-позиции VIP/Premium/Legend и кейсы не являются подтверждёнными товарами серверов. Перед запуском продаж замени названия, описания и цены на проверенные условия каждого сервера. Не выдавай демо-каталог за официальный.
Кейсы в этой версии — фиксированные наборы, не платные случайные розыгрыши.
Владельцу нужно вручную выдать оплаченный серверный товар после уведомления о заказе. Автоматическая выдача требует API/панели конкретного сервера.
Подарок Telegram «Мишка» не добавлен в каталог автоматически: наличие и возможность отправки зависят от доступных Telegram gifts и баланса Stars бота.

## Запуск локально
1. Установи Python 3.10+.
2. Установи зависимости:
   `pip install python-telegram-bot==22.8 Flask requests`
3. Создай бота через @BotFather и скопируй токен.
4. Задай переменные окружения:
   - `BOT_TOKEN` — токен.
   - `WEBAPP_URL` — HTTPS-адрес опубликованного Mini App.
   - `OWNER_USERNAME` — username владельца без @, по умолчанию cmeptyug.
5. Размести папку `webapp` на HTTPS вместе с Flask-приложением (например, на VPS/Render/Railway с постоянным диском для SQLite).
6. Запусти `python bot.py`.
7. Открой бота и отправь `/start`.

## Для Android/Pydroid
Pydroid подходит для проверки polling-бота, но Telegram Mini App должен быть доступен по публичному HTTPS-адресу. `localhost` и обычный HTTP Telegram не примет как URL Mini App. Для постоянной работы нужен хостинг.

## Добавление/изменение товаров
Демо-каталог создаётся автоматически при первом запуске. Чтобы заменить его, останови бота, открой `cmeptb.sqlite3` совместимым SQLite-редактором и измени таблицу `products`, либо попроси подготовить отдельную защищённую админ-панель.
Поля: `server_key`, `kind` (`rank` или `case`), `title`, `price` (целое число Stars), `description`, `active`.

## Безопасность
- Никогда не отправляй токен бота посторонним.
- В production добавь HTTPS, резервные копии БД, защиту админ-панели, журнал заказов и обработку возвратов.
- Убедись, что все платежи проверяются на сервере, а `initData` проверяется по HMAC.
